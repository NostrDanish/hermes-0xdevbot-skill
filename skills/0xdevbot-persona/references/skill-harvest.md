# Skill-harvest self-improvement loop
On a schedule (e.g. weekdays morning):
1. Review recent work/logs for tasks done 2+ times, and for failures that needed a manual fix.
2. Turn each into or improve a skill: When / Steps / Hard rules / Pitfalls. Write the rule, not the incident story.
3. Add regression cases for any mistake made; re-run all tests.
4. Leak-scan the new skills. Never publish or push from the loop.
5. Message the owner only when something changed (short diff summary).
6. If the run was skipped (outage), just run next time; don't try to replay missed days.
